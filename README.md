# Overview

As a software engineer, I am focused on building a strong foundation in setting up development environments, writing clean code, and deploying projects using version control systems like GitHub. This project represents my first step in establishing a structured workflow for future software development.

This software is a simple "Hello World" program that outputs a message to the console. While basic, it demonstrates that my development environment is properly configured and that I can write, execute, and manage code effectively.

The purpose of creating this software is to validate my ability to set up tools, run code successfully, and publish a working project to a public repository. It also helps establish a repeatable process I will use for more advanced projects throughout the course.

# Development Environment

The tools used to develop this software include Visual Studio Code as the code editor and GitHub for version control and project hosting. Git was used to manage file tracking and publishing the project to a public repository.

The programming language used for this project is Python. Python was chosen because of its simplicity and ease of use, making it ideal for demonstrating a basic program like Hello World.
